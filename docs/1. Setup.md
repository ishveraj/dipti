## Setup
1. Requires npm installed locally in your machine
1. Open terminal where `package.json` is located to run npm codes
1. Run `npm install`
1. Run `npm start`
1. Open [http://localhost:3000](http://localhost:3000) to view app in the browser

## Local Development
1. `.env` - set `HUB_DOMAIN` to where `hub` folder is located.
1. `.env` - set `LOCALHOST_API_TOKEN`. You may generate a token from CMS > Users > Webmaster > Application passwords.

## CMS Installation in Server
1. Create `Database` in phpMyAdmin in server
1. Create `hub` folder in server
1. Upload Neo WP framework INTO `hub` folder in server
1. Run `npm run build-staging` and upload files into server (same level as `hub` folder)
1. Install CMS by visiting server URL with `/hub`
1. Follow steps below after logging into CMS

## CMS Admin Setup
1. Visit `Plugins` activate all plugins (Update if necessary)
1. Visit `Custom Fields` and click on `Sync available`. Tick all and use `Bulk Actions` to `Sync Changes`
1. Visit `Site Settings` fill up mandatory fields
1. Visit `Posts` and `Pages` and delete all including trash
1. Visit `Pages` and `Add New` page. Set template to `Home` and `Publish` (add more templates at `/public/backend/App/templates.php`)
1. Visit `Settings` and set `Timezone` to `Kuala Lumpur` or required timezone.
1. Visit `Settings > Reading` and set `A static page` to `Home`
1. Visit `Appearance > Menus` and create a new `Menu`. Ensure to tick `Display Location Navigation Links`
1. Update WP version if necessary

## Staging Deployment
1. Run `npm run build-staging`
1. `dist` - upload contents of folder into staging server
1. `manifest.json` is auto generated when site settings is saved in CMS hence does not require to be done manually

## Production Deployment
1. Run `npm run build-production`
1. `dist` - upload contents of folder into live server
1. Visit `Site Settings > Clear Cache` to clear cache data

## CMS DB Migration
1. Export DB from phpMyAdmin
1. Ensure Operation Corrolation of DB is the same
1. Import DB into new server
1. Set wp-options > `siteurl` AND `home` to new domain URL
1. Login to WP Admin AND use `Better Search Replace` OR any plugins to replace DB URLs to new URL
1. **AVOID** manually replacing URLs in SQL file
